Raycaster

Raycasting is a rendering technique to create a 3D perspective in a 2D map. Raycasting can go very fast, because only a calculation has to be done for every vertical line of the screen.

The map is a 2D square grid, and each square can either be (0 = no wall), or a positive value (= a wall with a certain color or texture).

Assume every vertical strip of the screen is x (i.e 0 to SCREEN_WIDTH) and it send out a ray that starts at the player location and with a direction that depends on both the player's looking direction, and the x-coordinate of the screen. Then, let this ray move forward on the 2D map, until it hits a map square that is a wall. If it hit a wall, calculate the distance of this hit point to the player, and use this distance to calculate how high this wall has to be drawn on the screen, the further away the wall, the smaller it's on screen, and the closer, the higher it appears to be. These are all 2D calculations.

Source: https://github.com/mousammm/Raycaster

1.2 Inputs

ROTATION.

  A { // left
    float oldDirX = dirX;
    dirX = dirX * cosf(rotSpeed) - dirY * sinf(rotSpeed);
    dirY = oldDirX * sinf(rotSpeed) + dirY * cosf(rotSpeed);
    float oldPlaneX = planeX;
    planeX = planeX * cosf(rotSpeed) - planeY * sinf(rotSpeed);
    planeY = oldPlaneX * sinf(rotSpeed) + planeY * cosf(rotSpeed);
  }
  D { // right
    float oldDirX = dirX;
    dirX = dirX * cosf(-rotSpeed) - dirY * sinf(-rotSpeed);
    dirY = oldDirX * sinf(-rotSpeed) + dirY * cosf(-rotSpeed);
    float oldPlaneX = planeX;
    planeX = planeX * cosf(-rotSpeed) - planeY * sinf(-rotSpeed);
    planeY = oldPlaneX * sinf(-rotSpeed) + planeY * cosf(-rotSpeed);
  }

dt: deltatime, time passed between 2 frames for smooth and uniform movenent across different fps.

FORWARD AND BACKWARD.

  W {
    // no collision
    posX += dirX * moveSpeed;
    posY += dirY * moveSpeed;

    // with collision
    if (worldMap[(int)posY][(int)(posX + dirX * moveSpeed)] == 0) posX += dirX * moveSpeed;
    if (worldMap[(int)(posY + dirY * moveSpeed)][(int)posX] == 0) posY += dirY * moveSpeed;
  }

  S {
    // no collision
    posX -= dirX * moveSpeed;
    posY -= dirY * moveSpeed;

    // with collision
    if (worldMap[(int)posY][(int)(posX - dirX * moveSpeed)] == 0) posX -= dirX * moveSpeed;
    if (worldMap[(int)(posY - dirY * moveSpeed)][(int)posX] == 0) posY -= dirY * moveSpeed;
  }

  for (int x = 0; x < SCREEN_WIDTH; x++) {
    // loop through every vertical column of the screen (from left: 0 to right: 639)

    float cameraX = 2.0f * (float)x / (float)SCREEN_WIDTH - 1.0f;

2.3 StepDist

    if (rayDirX < 0) { stepX = -1; sideDistX = (posX - mapX) * deltaDistX; }

    if (rayDirY < 0) { stepY = -1; sideDistY = (posY - mapY) * deltaDistY; }

    while (hit == 0) {
