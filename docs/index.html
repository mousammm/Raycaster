Raycaster

Raycasting is a rendering technique to create a 3D perspective in a 2D map. Raycasting can go very fast, because only a calculation has to be done for every vertical line of the screen.

The map is a 2D square grid, and each square can either be (0 = no wall), or a positive value (= a wall with a certain color or texture).

Assume every vertical strip of the screen is x (i.e 0 to SCREEN_WIDTH) and it send out a ray that starts at the player location and with a direction that depends on both the player's looking direction, and the x-coordinate of the screen. Then, let this ray move forward on the 2D map, until it hits a map square that is a wall. If it hit a wall, calculate the distance of this hit point to the player, and use this distance to calculate how high this wall has to be drawn on the screen, the further away the wall, the smaller it's on screen, and the closer, the higher it appears to be. These are all 2D calculations.

Source: https://github.com/mousammm/Raycaster

playerAngle: the direction the player is looking in (it is in RADIAN). We are initializing our player to look in the right direction.

playerMoveSpeed: how fast player will go up or dowm (will handle by W and S keys)

playerRotSpeed: how fast player will go left or right (will handle by A and D keys)

Camera // ...

  fov = 60.0 * (PI/180.0)

fov: this is the field of view, initialize to 60 deg and convert it radian. The more the fov is the we can see in the world.

Raymarching stuff // ...

  rayStepSize = 0.05

rayStepSize: as we are doing Raymarching, we need to define the steps the ray are goonna comes out of player. If we lower the step size to 0.01 we would see smooth edges but it can lower our performance.

Extra // this are helper variables not particularly required

  halfScreenHeight = screenHeight / 2
  halfFov = fov / 2

1.2 Inputs

Rotation // 

  A { playerAngle -= playerRotSpeed * dt }
  D { playerAngle += playerRotSpeed * dt }

dt: deltatime, time passes between 2 frames for smooth and uniform movenent across different fps. For if using raylib there is built in function, and if using SDL need to do the math for finding deltatime or use whatever you use.

Forward and Backward // 

  W {
    playerPosX += cos(playerAngle) * playerMoveSpeed * dt
    playerPosY += sin(playerAngle) * playerMoveSpeed * dt
  }

  S {
    playerPosX -= cos(playerAngle) * playerMoveSpeed * dt
    playerPosY -= sin(playerAngle) * playerMoveSpeed * dt
  }

Basic trigonometry to to move in the direction the player is looking to.

1.3 Raycasting

rayyyyycaster // 

  for (ray = 0; ray < screenWidth; ray ++) {
     rayAngle = (playerAngle - halfFov) + (ray / screenWidth) * fov
     rayDist  = 0.0

     for ( map[ (playerAngle + sin(rayAngle) * rayDist) 
                + (playerAngle + cos(rayAngle) * rayDist) 
                * mapWidth ] == 0 )
     { rayDist += rayStepSize }

     lineHeight = (screenHeight / rayDist) // this cause fish eye
     if (lineHeight > screenHeight) { lineHeight = screenHeight } 
      
     drawLine(ray, halfScreenHeight - lineHeight / 2,
              ray, halfScreenHeight + lineHeight / 2,
              RED)
  }

We loop the whole screen vertical strips from (0 to screenWidth).

rayAngle: we also need different angle for different ray this just tilts the ray aq to player left and right

rayDist: this is distance from the player to the wall.

we then check if the rayDist is on a empty space (i.e 0 on map) if yes we increase the ray with the rayStepSize, we will eventually hit the the wall and get the proper rayDist.

lineHeight: the height of the wall that will be used to draw on the screen.

also need to put some guard as lineHeight can also get bigger then the screenHeight itself then we clamp lineHeight to screenHeight

fish eye fix: lineHeight = (screenHeight / (rayDist * cos(rayAngle - playerAngle)))
