Raycaster

Raycasting is a rendering technique to create a 3D perspective in a 2D map. Raycasting can go very fast, because only a calculation has to be done for every vertical line of the screen.

The map is a 2D square grid, and each square can either be (0 = no wall), or a positive value (= a wall with a certain color or texture).

Assume every vertical strip of the screen is x (i.e 0 to SCREEN_WIDTH) and it send out a ray that starts at the player location and with a direction that depends on both the player's looking direction, and the x-coordinate of the screen. Then, let this ray move forward on the 2D map, until it hits a map square that is a wall. If it hit a wall, calculate the distance of this hit point to the player, and use this distance to calculate how high this wall has to be drawn on the screen, the further away the wall, the smaller it's on screen, and the closer, the higher it appears to be. These are all 2D calculations.

Source: https://github.com/mousammm/Raycaster

1.2 Inputs

ROTATION.

  A { playerAngle -= playerRotSpeed * dt }
  D { playerAngle += playerRotSpeed * dt }

dt: deltatime, time passed between 2 frames for smooth and uniform movenent across different fps.

FORWARD AND BACKWARD.

  W {
    playerPosX += cos(playerAngle) * playerMoveSpeed * dt
    playerPosY += sin(playerAngle) * playerMoveSpeed * dt
  }

  S {
    playerPosX -= cos(playerAngle) * playerMoveSpeed * dt
    playerPosY -= sin(playerAngle) * playerMoveSpeed * dt
  }

Basic trigonometry to to move in the direction the player is looking.

RAYCASTING WITH RAYMARCHING IMPLEMENTATION.

  for (ray = 0; ray < screenWidth; ray ++) {
     rayAngle = (playerAngle - halfFov) + (ray / screenWidth) * fov
     rayDist  = 0.0

     while (map[(int)(playerPosX + cos(rayAngle) * rayDist) +
                (int)(playerPosY + sin(rayAngle) * rayDist) *

     lineHeight = (screenHeight / rayDist) // this cause fish eye

  }

2.2 delta and Step Dist

lets start by computing the deltaDist and stepDist.

  // direction vectors of rayAngle
  rayDirX = cos(rayAngle)
  rayDirY = sin(rayAngle)
  
  // dist ray has to travel from player pos to the next grid line in x(vertically) and y.
  // prevent division-by-zero if running parallel to an axis.
  deltaDistX = (rayDirX == 0) ? 1e30 : abs(1.0 / rayDirX)
  deltaDistY = (rayDirY == 0) ? 1e30 : abs(1.0 / rayDirY)
  
  // dist of ray from player to the closet grid lines (not wall).
  sideDistX = 0.0
  sideDistY = 0.0
  
  // direction to step in the grid map (-1[back] or +1[front]), need cause map is flat array.
  stepX = 0
  stepY = 0
  
  // current integer square of the map the player is in
  mapX = int(playerPosX)
  mapY = int(playerPosY)
  
  // compute step and initial sideDist
  if (rayDirX < 0) {
      stepX = -1
      sideDistX = (playerPosX - mapX) * deltaDistX
  } else {
      stepX = 1
      sideDistX = (mapX + 1.0 - playerPosX) * deltaDistX
  }
  
  if (rayDirY < 0) {
      stepY = -1
      sideDistY = (playerPosY - mapY) * deltaDistY
  } else {
      stepY = 1
      sideDistY = (mapY + 1.0 - playerPosY) * deltaDistY
  }

2.3 DDA jump loop.

ddaLoop.

  sideHit = 0 
  // 0 : vertical wall (x-axis on grid line)
  // 1 : horizontal wall (y-axis on grid line)

  while (map[mapY * mapWidth + mapX] == 0) {
      // jump to the next closest grid line (either X line or Y line)
      if (sideDistX < sideDistY) {
          sideDistX += deltaDistX
          mapX += stepX
          sideHit = 0
      } else {
          sideDistY += deltaDistY
          mapY += stepY
          sideHit = 1
      }
  }

2.4 Draw Wall.

draw wall.

  // perpendicular distance to the wall (automatically fixes fish-eye)
  perpWallDist = 0.0
  if (sideHit == 0) {
      perpWallDist = sideDistX - deltaDistX
  } else {
      perpWallDist = sideDistY - deltaDistY
  }
  if (perpWallDist < 0.01) { perpWallDist = 0.01 }
  
  lineHeight = screenHeight / perpWallDist
  drawLine(ray, halfScreenHeight - lineHeight / 2,
