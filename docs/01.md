# Outer Looping

- we loop `for (x = 0; x < 640; x += 1)`
- the middle pixel `640/2 = 320`px ray angle is `PlayerAngle`
- so we have a `FOV` for 60
    ```
    pa = PlayerAngle
    x     =    1   .... 320 ....   640
    angle = (pa-30)     pa       (pa+30)
    ```
- think of 640 pencil standing from left to right 
- the middle pixel (x = 320) has a angle equal to  `PlayerAngle` but what about x(0...319,320,321...640)
- `angle = (PlayerAngle - HalfFov) + (x/Width) * FOV`
    - this line of code give angle for every x (0 to 640)

```
for x: i32 = 0; x < WIDTH; x += 1 {
  // Get the ray angle per `x`
  angle := (PA - HALF_FOV) + (f32(x) / f32(WIDTH)) * FOV_RAD
  dist: f32 = 0.0

  // Step till we hit a wall, increasing the dist
  for MAP[i32(PY + math.sin(angle) * dist) * MAP_W + i32(PX + math.cos(angle) * dist)] == 0 {
      dist += STEP_SIZE
  }

  // Draw the map
  h := i32(f32(HEIGHT) / dist)
  if h > HEIGHT do h = HEIGHT
  rl.DrawLine(x, HALF_HEIGHT - h/2, x, HALF_HEIGHT + h/2, rl.RED)
}
```

# Inner Looping
```
for MAP[i32(PY + math.sin(angle) * dist) * MAP_W + i32(PX + math.cos(angle) * dist)] == 0 {
    dist += STEP_SIZE
} 
```
- so the inner loop increases from player position to the angle for its x with its STEP_SIZE
- and at the end we multiply with `MAP_W` to turn it into map cordinate and check if it's a empty space and increases the `dist += STEP_SIZE`

## height from the player distance to the wall
```
h := i32(f32(HEIGHT) / dist)
```
- player *near* to wall :  height is big
- player *far*  to wall :  height is small

* dist = 1.0
    - h = (HEIGHT / 1.0)
    - h = 480 : height of the wall
    - height is big
 
* dist = 4.0
    - h = (HEIGHT / 4.0)
    - h = 120 : height of the wall
    - height is small

* dist = 0.1 (inside the wall)
    - h = (HEIGHT / 0.1)
    - h = 480000 : height of the wall
    - clamp it : `if dist < HEIGHT do h = HEIGHT
